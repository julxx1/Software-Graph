# Software Graph

Mapa interactivo 2D y 3D del proyecto Software: documentos, servicios, paquetes, embudo, pendientes y decisiones, con archivos descargables (PDF, DOCX, MD, TXT, HTML, JSON, CSV, JPG y ZIP).

- Sitio: https://julxx1.github.io/Software-Graph/
- Un solo archivo (`index.html`), sin dependencias externas. También se puede abrir descargándolo y haciendo doble clic.
